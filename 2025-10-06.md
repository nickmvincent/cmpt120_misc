Three accumulator patterns we see in 120 (might be weird if you're used to just using .append())

```python
# first we get the sum
number_we_want = 0 # init a number outside a loop
for num in [10, 20, 30]:
    number_we_want += num
print(number_we_want)

# second we get the mean
number_we_want = 0 # init a number outside a loop
my_list = [10, 20, 30]
for num in my_list:
    number_we_want += num
print(number_we_want / len(my_list))

# third we "accumulate" on a string
# make a new string for each a and b character in my_string

my_string = "abaaababaccccccaa"
new_str = "" # our var initialized outside our loop
for char in my_string:
    if char == "a" or char == "b":
        new_str += char
print(new_str)

# fourth doing it with a list
# getting all items with "red" substring in the string
my_list = ["applered", "bananablue", "appleblue", "bananared"]
new_list = []
for item in my_list:
    if "red" in item:
        new_list += [item]
print(new_list)
```
