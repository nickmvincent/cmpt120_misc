Algorithm Quality

How do we measure if code is "Good"? It's not just about speed.

Qualitative Measures

  • Correctness: Does it actually solve the problem?
  • Readability: Can others (and future you) debug it?
  • Robustness: Does it handle bad input without crashing?

Quantitative Measures

  • Time Complexity: How execution time grows with input.
  • Space Complexity: How memory usage grows with input.

Benchmarking with Python

timing_example.py
import time

# 1. Start the clock
start_time = time.time()

# --- Code to Measure ---
total = 0
for i in range(1000000):
    total += i
# -----------------------

# 2. Stop the clock
end_time = time.time()

# 3. Calculate difference
duration = end_time - start_time
print(f"Execution took: {duration:.5f} seconds")

Merge Sort

Time: O(n log n) Space: O(n)

Selection sort is O(n²). When n gets large (e.g., 1,000,000 items), Selection Sort is too slow. Merge Sort uses a recursive "Divide and Conquer" strategy to go faster.

Input Size (n) Selection Sort O(n²) Merge Sort O(n log n)
1,000 1,000,000 ops ~10,000 ops
1,000,000 1 Trillion ops (Years) ~20 Million ops (Seconds)

The Logic

  1. Split: Recursively split the list in half until you have lists of size 1.
  2. Merge: Compare the smallest items of two sublists and zip them together into a new sorted list.
Note: Merge Sort requires "Extra Space" to create the new lists during the merge phase.
merge_sort.py
def merge_sort(alist):
    # Base case: List is a single item
    if len(alist) <= 1:
        return alist

    mid = len(alist) // 2
    
    # Recursive Split
    left = merge_sort(alist[:mid])
    right = merge_sort(alist[mid:])

    # Merge Step
    return merge(left, right)

Recursion Gym

Specific practice problems from the course deck.

1. Sum Integers 1 to N

Calculate sum of 1, 2, ... n.
recursive_sum(5) -> 15

def recursive_sum(n):
    if n == 0: return 0        # Base Case
    return n + recursive_sum(n - 1)

2. Reverse a String

recursive_reverse("hello") -> "olleh"

Hint: Take the last char, add it to the reverse of the rest.

def recursive_reverse(s):
    if len(s) <= 1: return s   # Base Case
    # Last char + Reverse of (all chars except last)
    return s[-1] + recursive_reverse(s[:-1])

3. Palindrome Checker

Check if string reads same forward/backward.
racecar -> True

def is_palindrome(s):
    if len(s) <= 1: return True # Base Case
    if s[0] == s[-1]:           # Outer chars match?
        return is_palindrome(s[1:-1]) # Check middle
    return False

4. Count Vowels

Count 'a,e,i,o,u' in a string recursively.

def count_vowels(s):
    if not s: return 0          # Base Case
    
    is_vowel = 1 if s[0].lower() in "aeiou" else 0
    return is_vowel + count_vowels(s[1:])

5. Challenge: Nested List Sum

Sum all numbers, even inside lists of lists.
[1, [2, 3], 4] -> 10

Hint: Use isinstance(item, list).

def nested_sum(data):
    total = 0
    for item in data:
        if isinstance(item, int):   # Base Case (for item)
            total += item
        elif isinstance(item, list): # Recursive Case
            total += nested_sum(item)
    return total
