Does not depend on list size. One operation.

The problem space is cut in half every iteration.

while n > 1:
    n = n // 2  # Divide by 2
Linear Time O(n)

Iterates through the input once.

for item in arr:
    print(item)
Quadratic O(n²)

Nested loops. For every item, loop through all items.

for i in range(n):
    for j in range(n):
        print(i, j)

Selection Sort

Time: O(n²) Space: O(1)

The strategy is simple: Search for the smallest item in the unsorted pile, and swap it into the correct spot.

The Algorithm Steps

  1. 1

    The Outer Loop

    Iterate through each position in the list (from 0 to n-1). This position i is where we want to put the next smallest number.

  2. 2

    Find Minimum

    Start assuming the element at i is the smallest. Run an inner loop from i+1 to the end. If you find a smaller number, update your record of the min_index.

  3. 3

    The Swap (Using Temp)

    Once the inner loop finishes, swap the value at i with the value at min_index using a temporary variable.

Python Implementation

selection_sort.py Python 3 
def selection_sort(arr):
    n = len(arr)
    
    # Traverse through all array elements
    for i in range(n):
        
        # Step 1: Assume current index is minimum
        min_index = i
        
        # Step 2: Find the actual minimum in remainder
        for j in range(i + 1, n):
            if arr[j] < arr[min_index]:
                min_index = j
        
        # Step 3: Swap using a temporary variable
        # (We save the value of arr[i] into temp, 
        #  overwrite arr[i], then restore temp)
        temp = arr[i]
        arr[i] = arr[min_index]
        arr[min_index] = temp

data = [64, 25, 12, 22, 11]
selection_sort(data)
print(data)

Binary Search

Time: O(log n) Pre-req: Sorted Data

Don't check one by one. Jump to the middle. Is it higher? Lower? Eliminate half the universe with every guess.

Linear Search (The Slow Way)

# O(n)
def linear_search(arr, target):
    # Check every single item
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1

Good for unsorted data. Bad for big lists.

Binary Search (The Fast Way)

# O(log n)
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1

    while low <= high:
        # Integer Division
        mid = (low + high) // 2
        
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            # Discard left half
            low = mid + 1
        else:
            # Discard right half
            high = mid - 1
            
    return -1
Critical Implementation Details:
  • Use // for index division (integers only).
  • The loop condition must be low <= high to catch the last item.
  • Move boundaries by mid + 1 or mid - 1, not just mid.

Recursion

A function that calls itself. It's not magic; it's a stack of tasks. We solve a big problem by solving a slightly smaller version of it.

How to "Find" the Recursive Solution

🧠 The "Delegation" Metaphor

Imagine you are a manager who is very lazy. You are given a task (like summing a list).

You don't want to do the whole thing. So, you do one tiny piece (handle the first number) and pass the rest of the list to your clone.

Total = My_Number + Clone_Do_Rest()

✨ The Recursive Leap of Faith

When writing the code, assume the recursive call works.

Don't try to simulate the whole stack in your head immediately. Just ask: "If factorial(n-1) gave me the correct answer for the smaller number, what would I do with it to solve n?"

return n * (Answer_From_Smaller_Step)

The 3 Laws of Recursion

1

The Base Case

The condition that stops the recursion. "When is the problem so simple I know the answer immediately?"

if n == 0: return
2

Change of State

The data passed to the next call must be smaller. You must move *towards* the Base Case.

factorial(n - 1)
3

Self-Reference

The function must call itself to solve the smaller sub-problem.

Visualizing the Call Stack

Notice how the function "pauses" to go deeper, then returns to finish drawing.

Try it yourself: Python Turtle

This code uses the turtle library to draw the tree above. Copy this into IDLE or VS Code.

import turtle

def draw_tree(t, branch_len):
    # 1. Base Case
    if branch_len < 5:
        return

    # Draw trunk
    t.forward(branch_len)
    
    # 2. Recurse Right
    t.right(20)
    draw_tree(t, branch_len - 15)
    
    # 3. Recurse Left (Backtrack 20, then Left 20 = Left 40 total shift)
    t.left(40)
    draw_tree(t, branch_len - 15)
    
    # 4. RESTORE STATE (Backtrack)
    # We must return the turtle to the start of this branch
    # so the previous function call can continue correctly.
    t.right(20)
    t.backward(branch_len)

# Setup the screen
t = turtle.Turtle()
screen = turtle.Screen()
t.left(90)      # Point up
t.speed(1)      # 1 = Slowest, 10 = Fast
t.color("green")

# Start Recursion
draw_tree(t, 75)
turtle.done()

Practice Problems

1. Recursive Factorial

Calculate n!. Remember: 5! = 5 * 4!.

▶ How to think about this

1. The Lazy Manager: I want 5!. I will keep the 5, and tell my clone to calculate 4!.

2. Base Case: If I ask for 0!, I know the answer is 1 immediately.

3. Leap of Faith: Trust that factorial(n-1) works. Multiply n by that result.

def factorial(n):
    # Base Case: simplest possible input
    if n == 0: 
        return 1
    # Recursive Step: n * (result of smaller problem)
    return n * factorial(n - 1)

2. Sum a List

Sum list [1, 2, 3] using recursion (no loops).

▶ How to think about this

1. The Lazy Manager: I have a list. I'll take the first number (head) for myself. I'll pass the rest (tail) to my clone.

2. Base Case: If the list is empty, the sum is 0.

3. Leap of Faith: arr[0] + sum_list(arr[1:])

def sum_list(arr):
    # Base Case: Empty list
    if not arr: 
        return 0
    # Recursive Step: Head + Sum(Tail)
    return arr[0] + sum_list(arr[1:])
